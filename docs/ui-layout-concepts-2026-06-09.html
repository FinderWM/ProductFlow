workspace concept / review draft

保留经典布局，新增一套更安静的工作台布局。

大窗口布局方案只在顶部菜单切换；小窗口收入操作球。主页只展示一级菜单入口和页面职责，具体新建、编辑、预览、保存等动作进入子页面完成。

00 / responsive behavior

新 UI 继承窗口大小适应逻辑。

当前窗口变化逻辑需要在 `workspace` 中完整体现：宽屏三栏，中等宽度弱化侧栏和右侧面板，移动端退回单列任务流与底部导航。

1440 / desktop

三栏工作台

导航 rail、主内容、上下文 inspector 同屏，适合长时间操作。

1024 / compact

侧栏压缩

rail 只保留图标，右侧 inspector 可折叠或转为浮层。

390 / mobile

单列任务流

页面内容纵向排列，设置、历史、筛选进入 sheet，主操作沉到底部。
